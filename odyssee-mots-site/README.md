# Odyssée Mots — site vitrine

Site statique prêt pour GitHub Pages.

## Fichiers
- `index.html` : accueil
- `mode-emploi.html` : présentation du fonctionnement
- `confidentialite.html` : politique de confidentialité
- `styles.css`, `script.js`, `assets/` : mise en page et visuels

## Publication sur GitHub Pages
1. Créer un dépôt GitHub, par exemple `odyssee-mots-site`.
2. Déposer **tout le contenu** de ce dossier à la racine du dépôt (pas le dossier parent).
3. Dans GitHub : **Settings → Pages**.
4. Choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis enregistrer.
5. Après publication, l’adresse du site sera de la forme `https://VOTRE-PSEUDO.github.io/odyssee-mots-site/`.
6. Le lien de confidentialité à déclarer dans App Store Connect sera alors :
   `https://VOTRE-PSEUDO.github.io/odyssee-mots-site/confidentialite.html`

## Avant publication
La politique de confidentialité est une base de travail. Compléter les coordonnées de l’éditeur et vérifier les flux réels : prestataire d’IA, données transmises, hébergement, durée de conservation, SDK, journaux techniques et abonnements.
